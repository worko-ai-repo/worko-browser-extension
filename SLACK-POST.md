# 🚀 Worko Browser Extension - Ready for Testing!

Hey team! 👋 

The **Worko Browser Extension** is ready for its first round of testing! This extension brings our job matching intelligence directly to LinkedIn, Naukri, and NaukriGulf job pages.

## 🎯 What it does:
- **Job Scoring**: Automatically analyzes job compatibility with user profiles
- **Skills Matching**: Shows which skills match and which need development  
- **Smart Apply**: Integrates with platform apply buttons
- **Real-time Analysis**: Works directly on job detail pages

## 📥 How to install:
1. Download `worko-extension-dev.zip` from [shared location]
2. Extract the zip file
3. Open Chrome → `chrome://extensions/`
4. Enable **Developer mode** (top-right toggle)
5. Click **"Load unpacked"** → Select extracted folder
6. Look for Worko icon in your toolbar! 🎉

## 🧪 What to test:
- Visit job pages on **LinkedIn**, **Naukri.com**, or **NaukriGulf.com**
- Look for the **Worko banner** on job detail pages
- Click **"Score Job"** to test matching
- Try **"View Details"** for breakdown analysis
- Test the **"Apply"** button integration

## 🐛 Found issues?
- Check browser console (F12) for error messages
- Note the job platform and URL where issues occur
- Share screenshots if UI looks broken

## 📋 Platforms supported:
✅ LinkedIn job detail pages  
✅ Naukri.com job pages  
✅ NaukriGulf.com job pages
