# Worko Extension Icons

This directory should contain the following PNG icon files:

- `icon16.png` - 16x16 pixels
- `icon32.png` - 32x32 pixels  
- `icon48.png` - 48x48 pixels
- `icon128.png` - 128x128 pixels

## Icon Design
- Background: Worko brand color (#170155)
- Content: White "W" or Worko logo
- Style: Rounded corners (20% border-radius)

## Temporary Solution
For now, the extension will work without icons. Add proper PNG files later.

## SVG Assets
- `worko-logo.svg` - Main logo for popup header
- `icon16.svg`, `icon32.svg` - SVG versions for reference
